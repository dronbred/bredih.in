# Дизайн сайта

Сделано по скиллу `.claude/skills/frontend-design` и мудборду проекта.

## Бриф

- Предмет: соло-разработчик, который автоматизирует процессы малого и среднего бизнеса, делает сайты, Telegram-ботов и приложения.
- Аудитория: владельцы и руководители бизнеса без технического бэкграунда.
- Главная задача страницы: человек понимает, что рутину можно отдать, и пишет в Telegram.

## Токены

| Токен | Цвет | Роль |
|---|---|---|
| ink | `#17212B` | Текст и тёмные блоки. Цвет тёмной темы Telegram, а не «почти чёрный» |
| paper | `#FFFFFF` | Фон страницы |
| fog | `#EEF2F6` | Фон второстепенных секций и полей |
| wire | `#CBD5DF` | Линии схемы и разделители |
| signal | `#2AABEE` | Действия и активный шаг схемы. Синий Telegram, родной для аудитории ботов |
| done | `#31B26A` | Только для завершённого шага схемы и метрик результата |

Шрифты: **Unbounded** (заголовки, широкий геометрический гротеск с хорошей кириллицей) и **Golos Text** (основной текст, сделан для русскоязычных интерфейсов). Оба подключены локально через Fontsource.

Шкала: 15/17 px текст, заголовки через `clamp()`, длина строки до ~70 знаков.

Выравнивание по левому краю везде, кроме 404.

## Принципы

1. Одна запоминающаяся вещь: живая схема автоматизации на первом экране. Шаги загораются по очереди, как сценарий, который выполняется сам. Остальная страница спокойная.
2. Никаких надписей капсом над заголовками, стрелок в ссылках и точек-разделителей. Заголовок секции говорит сам за себя.
3. Нумерация только у процесса работы, потому что это последовательность.
4. Движение только в схеме на первом экране. С `prefers-reduced-motion` схема сразу показана в конечном состоянии.
5. Скругления по иерархии: кнопки 999px, поля 12px, крупные блоки 24px.

## Проверка плана против дефолтов

- Сначала был вариант индиго-градиент, карточки услуг с иконками-эмодзи и капс-надписи над каждым заголовком. Это SaaS-шаблон, его убрал.
- Тёмный «неоновый» стиль отклонён: им пользуются конкуренты из мудборда (шаблоны AI automation agency).
- Синий выбран не как «безопасный», а потому что это цвет Telegram, через который клиент и будет писать. Отличие задают шрифт Unbounded и схема на первом экране.
